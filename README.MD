Rearrange
=========

This module is used fpr rearranging names.
tURNS "LastName, FirstName" into "FirstName LastName".

## Example

* Calling `rearrange_name("Turing, Alan")` will return `"Allan Turing"`
* Calling `rearrange_name("Hopper M., Grace")` will return `"Grace M. Hopper"`
* Calling `rearrange_name("Voltaire")` will return `"Volataire"`
