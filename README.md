Rearrange
=========
this module is used for rearranging names .
turns "lastname , first name" into "firstname , lastname".
##Example
* calling 'rearrange("turing","alan")'returns "alan turing"
* calling 'rearrange("hopper M.","grace")'returns "grace hopper M."
* calling 'rearrange("voltaire")'returns "voltaire"
