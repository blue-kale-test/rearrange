Rearrange
=========

This module is used for rearranging names.
Turns "Last Name, First Name" into "First Name, Last Name".

## Example

 * Calling `rearrange_name("KYABU, Lucien")` will return `"Lucien KYABU"`
 * Calling `rearrange_name("KABALA, Mungomba")` will return `"Mungomba KABALA"`
 * Calling `rearrange_name("Toshinori")` will return `"Toshinori"`
