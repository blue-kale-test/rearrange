Rearrange
=========

This module is used for rearranging names.
It turns "LastName, FirstName" into "FirstName LastName".

## Examples

* Calling `rearrange_name("Turing, Alan")` will returns `"Alan Turing"`.
* Calling `rearrange_name("Radhakrishnan, Abhiram")` will returns `"Abhiram Radhakrishnan"`.
* Calling `rearrange_name("U. Dheen, sharaf")` will returns `"Sharaf U. Dheen"`.
