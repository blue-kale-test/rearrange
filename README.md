Rearrange
=========

This module is used for rearranging names.
Turns "LastName, FirstName" into "FirstName LastName".

## Examples

    * Callubg 'rearrange_name("Turing, Alan")' will return '"Alan Turing"'.
    * Callubg 'rearrange_name("Hopper, Grace M.")' will return '"Grace M. Hopper"'.
    * Callubg 'rearrange_name("Voltaire")' will return '"Voltaire"'.
